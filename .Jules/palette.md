## 2024-04-04 - ARIA Live with Icon Controls
**Learning:** When adding `aria-label` to state-changing icon controls (like Zoom In/Out), always combine it with `aria-live="polite"` on the adjacent element displaying the resulting state value to ensure a complete screen reader feedback loop.
**Action:** Apply this pattern consistently across all similar interactive controls.
